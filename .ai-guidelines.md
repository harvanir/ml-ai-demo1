# AI Assistant Development Guidelines

## 🎯 Development Workflow

### Pre-Change Checklist
**SELALU LAKUKAN SEBELUM melakukan perubahan apa pun:**

1. ✅ **Run Baseline Tests**
   ```bash
   # Unit tests (wajib)
   cd python && python -m pytest tests/ -v

   # Integration tests (jika ada)
   python -m python.tests.test_ml_demo
   python -m python.tests.test_ml_patterns
   ```

2. ✅ **Verify No Errors**
   - Pastikan semua test PASS (exit code 0)
   - Jika ada error, perbaiki dulu sebelum lanjut
   - Catat error yang ditemukan

3. ✅ **Make Changes**
   - Lakukan perubahan yang diminta
   - Update dokumentasi jika diperlukan
   - Pastikan perubahan incremental (kecil-kecil)

4. ✅ **Test After Changes**
   - Jalankan semua test lagi
   - Pastikan tidak ada regression
   - Verifikasi fungsionalitas masih berjalan

## 📋 Task-Specific Instructions

### File Organization Tasks
```
LAKUKAN TESTING TERLEBIH DAHULU sebelum memindahkan atau mengorganisir ulang file.
Jalankan baseline test, pastikan PASS, baru lakukan perubahan struktur.
```

### Code Refactoring Tasks
```
CEK ERROR TERLEBIH DAHULU sebelum melakukan refactoring.
Pastikan kode berjalan dengan baik sebelum mengubah struktur.
```

### Configuration Changes
```
TEST CONFIGURASI TERLEBIH DAHULU sebelum mengubah environment variables.
Verifikasi bahwa aplikasi masih berjalan dengan konfigurasi baru.
```

### Documentation Updates
```
UPDATE README.md jika ada perubahan workflow atau instruksi.
Pastikan semua command dan path masih akurat.
```

## 🔧 Quality Assurance

### Testing Requirements
- **Unit Tests**: Harus pass sebelum dan sesudah perubahan
- **Integration Tests**: Harus berjalan tanpa error
- **Manual Tests**: Jalankan script demo untuk memastikan fungsionalitas
- **Configuration Tests**: Pastikan environment variables berfungsi

### Error Handling
- **Syntax Errors**: Perbaiki segera, jangan lanjut sebelum fix
- **Import Errors**: Pastikan semua dependencies terinstall
- **Path Errors**: Verifikasi semua file path benar
- **Configuration Errors**: Test dengan environment variables berbeda

### Documentation Standards
- Update README.md jika ada perubahan workflow
- Update file konfigurasi jika ada perubahan setup
- Pastikan instruksi command masih akurat
- Tambahkan komentar di kode untuk perubahan kompleks

## 🚨 Critical Rules

1. **NO CHANGES WITHOUT TESTING FIRST**
2. **FIX ERRORS BEFORE PROCEEDING**
3. **VERIFY FUNCTIONALITY AFTER CHANGES**
4. **UPDATE DOCUMENTATION ACCURATELY**
5. **COMMIT INCREMENTAL CHANGES**

## 🎯 Best Practices

### Development Principles
- **Test-Driven Development**: Test dulu, baru ubah
- **Incremental Changes**: Lakukan perubahan kecil-kecil
- **Backup First**: Pastikan ada backup sebelum perubahan besar
- **Document Everything**: Catat setiap perubahan yang dilakukan

### Communication
- **Clear Instructions**: Berikan instruksi yang spesifik
- **Expected Outcomes**: Jelaskan hasil yang diharapkan
- **Error Reporting**: Laporkan error dengan detail
- **Progress Updates**: Update progress untuk tugas kompleks

### Code Quality
- **Consistent Formatting**: Ikuti style guide proyek
- **Meaningful Names**: Gunakan nama variable/fungsi yang jelas
- **Error Messages**: Berikan error messages yang informatif
- **Type Hints**: Tambahkan type hints jika memungkinkan

## 🔍 Troubleshooting

### Common Issues
- **Module Not Found**: Pastikan di folder python/ untuk import
- **Path Errors**: Gunakan relative path dari lokasi script
- **Environment Variables**: Pastikan .env file di root directory
- **Test Failures**: Jalankan test individual untuk debug

### Debug Commands
```bash
# Check current directory
pwd

# List files
ls -la

# Check Python path
python -c "import sys; print(sys.path)"

# Test specific module
python -c "import tests.test_anomaly_detector"
```
